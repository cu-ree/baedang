분기별 금액은 각 분기보고서의 누계 배당금을 차감해 산출했습니다.

아모레퍼시픽은 반기마다 배당하며 2025년 합계 1,240원을 지급했습니다.

최근 4년 동안 배당이 매년 늘었습니다. 다만 2022년에는 배당금이 980원에서 680원으로 30.6% 줄었습니다. 특별배당이 있었던 해의 기저효과일 수 있어 원문 확인이 필요합니다.
